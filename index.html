🚀 Panduan Deployment

1Buat Google Spreadsheet baru → Extensions › Apps Script → tempel isi file code.gs → jalankan fungsi setup() sekali → Deploy › New deployment › Web app (Execute as: Me, Access: Anyone) → tidak perlu memasukkan URL karena aplikasi berjalan langsung dari Web App ini.
2Isi data kejadian langsung di Spreadsheet (struktur kolom ada di Dashboard saat data kosong), atau input lewat aplikasi — termasuk 📍 perekaman koordinat GPS dan 📷 foto dari kamera HP.
3GitHub: buat repository baru, unggah index.html → Settings › Pages › Deploy from branch (main) → aplikasi online. GPS & kamera membutuhkan HTTPS — GitHub Pages sudah HTTPS.
